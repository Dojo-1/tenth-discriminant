# Phase 6 preregistration: operators on valid local examples

Date: 2026-10-23. Base: merged PR #24, `bf9ddff`. This protocol precedes
new Lean proof edits. “Valid” here means the explicit, coordinatewise
order-zero congruence for a fixed pair `(D,p)`, not class number one.

## Typed operator atlas

Write `F(D,p,a)` for `p | (a^p - conjugate(a))` in **both** integer-pair
coordinates. Three candidate operators have different domains:

1. `C : a ↦ conjugate(a)` at fixed `(D,p)`. Because conjugation is a ring
   involution fixing rational integers, `F(D,p,a) ⇒ F(D,p,C(a))`. Moreover
   `C² = id`. This is the bounded Lean target of this phase.
2. `T` replaces `D` and/or `a` by congruent residues modulo `p`. The pair
   multiplication is polynomial in these data, so `F` should be invariant.
   This is a **paper deduction to test later**, not a Lean claim in this phase.
3. `A` adjoins samples satisfying `F` to a finite sample set. Pointwise
   row divisibility then persists and its sums keep the original sample
   multiplicities. This is conditional on the still-unproved row-action
   identity for the actual Gram, not a determinant theorem by itself.

The formal closure generated by `C` has at most two samples, `{a,C(a)}`.
The proposed closure under `T` is a residue fiber, not a classification
of fundamental discriminants. Neither operator preserves the global
class-number hypothesis, the radius count, or an analytic cutoff by
definition. Matrix basis change is another typed operation: it preserves
the determinant only after its action on the original derivative rows
is identified, which is not yet checked.

## Fixed test and falsifiers

Prove the implication `F(D,p,a) ⇒ F(D,p,C(a))` in Lean, with the same
`pairPow`, `pairConj`, and coordinate divisibility used by the current
jet theorem. Verify involution and a non-real sample; preserve the
existing noninert `D=2,p=3` falsifier. Do **not** conclude that every
sample or every `D` is valid. In particular, applying a transformation
to a valid local residue never licenses a global class-number claim.

Run targeted Lean, source correspondence, full pinned build, dependency
audit and negative controls. Record failures; update reader-facing status
to distinguish the operator theorem from the still-open row identity,
inertness implication, radius formalization, and classification.

## Execution record

Protocol-only commit `6f45b4f` preceded the proof edit. The first
targeted Lean attempt failed because divisibility has no `.neg` field;
the repair used `dvd_neg`. A second attempt exposed Lean normalization
of the negative imaginary-coordinate difference, and another exposed
commutativity in the imaginary part of conjugated multiplication. These
were proof-script failures, not false mathematical claims. Targeted
compilation now passes for involution, multiplication and power transport,
congruence transport, its composition with the existing all-order jet
theorem, and the non-real `D=19,p=3` pilot. Source correspondence and
the 6695-step full Lean build also pass locally. Pinned CI and the
compiled audit/negative controls await the final commit.
