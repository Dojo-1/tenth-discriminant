# Phase368 — Polycosmic Adversarial Multi-Armed Bandit

Research-allocation organ layered over the existing [Phase306 arithmetic Worldlets](../phase306/) and [Phase367 original integer Gram factorization](../../lean/TenthDiscriminant/Phase367OriginalEvaluationFactor.lean). It **does not** infer mathematical truth, validate a new discriminant cutoff or operate a conscious mind.

`polybandit.py` is a deterministic, constrained, Pareto-UCB-like selector of **next investigations**, with typed local Worldlets, distinct fast/meso/review clocks, three-way obligations, mandatory source/remainder gates and optional human-review arms. `governance.pl` tests selected typed boundary rules independently of Python. `manifest.json` fixes the ontology, roles, transport remainder and falsifiers before any benchmark. `test_polybandit.py` tests safety/selection mechanics; synthetic receipts are not external proof.

Run `python3 -m unittest discover -s research/phase368 -p 'test_*.py' -v` and `python3 research/phase368/polybandit.py --budget 4 --rounds 5`. For GNU Prolog: `gprolog --consult-file research/phase368/governance.pl --query-goal phase368_main`. These commands do not run actual proof searches; they print proposals and control verdicts.

**Governance:** every external validation must have a separate registry and a source/scope-matched receipt. The Python policy cannot authenticate that registry and never promotes a claim. The experiments are not proof of enhanced intelligence or research throughput. Contrast with Phase306 D203 is opt-in and may not be used as an exact same-source field transport.
