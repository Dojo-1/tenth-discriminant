# R2: exact frame transport before richer routing

Frozen repository: Dojo-1/tenth-discriminant @ 791ebf4815d8eb4be5da3b01527ca7f0877b6d0e.
Prior granule experiment: 63bd235edbcf59800a1bce69436b5fa96b4769e0 (not assumed merged).
Protocol recorded before corpus generation and benchmark execution. This is a new
same-author methodology experiment, not a repair of R1's failed speedup claim.

## Fixed object and hypothesis
For rational bivariate F of exact positive Z-degree a, retain the original
(2a-1)-dimensional derivative Sylvester matrix. Transport under
T(F)(Z,W)=lambda F(u Z+h,v W+b), with lambda,u,v nonzero rationals.
Prediction: exact certificate reuse will avoid repeated determinants in a stream
of transformed instances. Additional benefit of hyperbolic eviction or adiabatic
context retention over exact canonical LRU is UNKNOWN, not presumed.

## Policies and information parity
All strategies see the same raw polynomial and get the same exact canonicalizer,
without generator orbit IDs or frame metadata. The canonicalizer handles scalar
multiplication and two translations when the top bidegree corner is nonzero;
unsupported shapes retain their raw identity. It does not claim a canonicalizer
for arbitrary affine scalings. All use the same seven canonical candidate points
[0,1,-1,2,-2,3,-3], transported back to the supplied object. No training.
Compare no reuse, raw-object LRU, canonical LRU, Euclidean-context eviction,
Poincare-context eviction, and both geometries with slow context (eta=1/4).
A canonical-unbounded policy is a separate memory-unmatched reference ceiling.
Bounded caches hold four accepted records each; all have the same admission gate.
The geometric policies use the same fixed coefficient-derived 3D ball coordinates;
only the distance and the context clock differ. Coordinates are not learned and
are not claims about the intrinsic geometry of mathematical research.
A hard exact bidegree change resets the slow context immediately.

## Corpus, budget and endpoints
Seeds 1701 and 2701; twelve base polynomials per seed; six rational transformed
instances per base. Twelve bases include eight corner-supported generic cases,
two repeated-factor controls, and two unsupported-corner cases. Three orderings:
blocked families, shuffled stream, and round-robin families. This yields six
streams of 72 tasks, 432 tasks/policy, all policies run on identical streams.
Related instances are intentionally repeated across policies/orders; this is not
unseen-task generalization. Generator IDs are only used for constructing/reporting
stream order, never passed to a strategy. Candidate exhaustion remains unresolved,
not proof of zero determinant. Cached exhausted records retain all checked zeros.

Primary metrics: production determinant calls, admission-oracle determinant calls,
record hits, accepted nonzero witnesses, unresolved tasks, false acceptances.
Resource ledger: normalization, routing, solving, admission, transport and total
wall time; cache entries and serialized record bytes. Timings are exploratory on
this container, with no speedup claim from one timing run. Benchmark executes all
policies once per stream, rotating policy order. Repeat normal and -O; compare
semantic outputs separately from timing. Each returned answer is additionally
checked against the global symbolic resultant before specialization, outside the
timed strategy; report this audit cost separately.

## Controls
Exact group action/composition/inverse; noncommuting affine examples; transported
witness values; translations, signs, tiny nonzero scaling; source/target identity;
fixed degree under specialization; reject zero scale, padded degree, wrong field,
wrong derivative convention, forged witnesses, and stale source records.
Nonzero determinant is never inferred from numerical similarity or cache distance.
Finite fuzzing uses separate fixed seed 3701. Include degree loss, identically zero
resultants, and changed-object lookalikes. Verify base and task duplicates explicitly.

## Gates
Reject any certificate policy if one invalid transport is accepted. Retain a
geometric/slow variant only if it reduces total determinant calls by >=10% versus
canonical LRU, with no worse calls on any stream, equal cache capacity, and no
false certificates. Wall-clock superiority requires a separate repeated resource
benchmark; a passing call-count criterion alone is not sufficient. If the simple
canonical policy ties/beats the richer ones, retain exact transport and stop adding
algebra/geometry. Do not retrofit coordinates or eta after seeing the result.
No quaternion, octonion or full hypercomplex-learning claim: affine maps have a
concrete associative noncommutative matrix algebra, which is tested directly.
No Lean source or numeric cutoff is changed by this experiment.
