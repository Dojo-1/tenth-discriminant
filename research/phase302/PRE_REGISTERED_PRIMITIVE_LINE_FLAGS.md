```
 d_S(x) = v5(gcd of B(x,e1), B(x,e2)) ∈ Z>=0.
```
For ANY integral primitive complement y with (x,y)∈GL2(R), set a=B(x,x) and c=B(x,y). Because the row (a,c) generates the intrinsic ideal (B(x,L)), the exact cross-image class of y in coker([a]) has order
```

 epsilon_S(x) = v5(q(x)) - d_S(x) = max(0,v5(a)-v5(c)).
```
This is a flagged-line invariant under *transport of both S and x*: (S,x)↦(TᵀST,T⁻¹x) for T∈GL2(R). It is also independent of y and of scaling x by a unit.
