## 1. The exact flagged local invariant [P-paper: elementary bilinear module theorem]

Let R=Z5, L≅R² a nondegenerate integral bilinear lattice with symmetric B and Gram S. For primitive x with `q(x)=B(x,x) ≠0`, define its *pairing/divisibility ideal* and valuation:

```
  I_L(x) = ( B(x,z) : z∈L ) ⊂ R,
  d_L(x) = v5(I_L(x)).
```

For ANY integral primitive complement y so (x,y)∈GL2(R), put a=B(x,x), c=B(x,y). The pairings of x with the full lattice are generated by (a,c). The actual order of the cross-class `[c] ∈ R/(a)` in the scalar Gram cokernel of the first attached line Rx is:

```
  ord([c])=5^epsilon_L(x),
  epsilon_L(x) = v5(a) − d_L(x)
               = max(0,v5(a)−v5(c)).
```

**Proof:** the order of c mod aR is p^{max(0,v_p(a)-v_p(c))}; the pairing ideal `(a,c)` has valuation min(v_p(a),v_p(c)). Because any two primitive complements differ by an integral unit multiple and an Rx multiple, this class order is independent of complement; and unit rescaling x leaves both q-valuation and I-depth invariant. Under a coordinate change T∈GL2(R) transporting **both** S→Tᵀ S T and x→T⁻¹x, both pairings and this order are literally preserved. A DIFFERENT flag x with the SAME S need not have the same epsilon. If q(x)=0 EXACTLY (a genuinely p5-isotropic vector), the one-dimensional rational orthogonal projector is not defined and epsilon is not a finite projection invariant; do not assign an artificial 'infinite mass' there.

For S=5^d U with U **nondegenerate modulo5**, a primitive x has `d_L(x)=d` because its pairing row Ux is nonzero modulo5. Hence `epsilon=v5(q(x))-d`; mod5 projective isotropic lines correspond precisely to flags with epsilon≥1. A nondegenerate binary form over F5 has either **zero or two simple projective zeros**. If two, the ordinary Hensel lemma lifts each simple projective root to a truly isotropic Q5 line. Its finite, nonisotropic nearby **integral primitive flags** can exhibit arbitrarily large finite epsilon even though the COMPLETE lattice is unchanged. Standard local-form prior art, e.g. Yuri Bilu's *p-adic numbers and Diophantine equations*, Theorem 6.1 (Hensel) and Lemma 11.3 (binary isotropy; 2014 revision), [Bilu lecture notes](https://cadadr.org/bordeaux-master/bilu-p-adic.pdf). No originality claim.

**Rank-one normalized mod5 reduction is not covered by that shortcut.** The primitive radical line can have the *pairing ideal itself* deeper than d; `epsilon=v5(q)-d_L(x)`, not v5(q)-d. Positive-definite rank1 toy `S=diag(1,25)`: x=e2 has mod5-zero norm, but v5(q)=v5(I_L(x))=2, epsilon0. Nondegenerate anisotropic toy `diag(1,2)` has zero obstructed mod5 primitive flags; positive-definite split toy `[[1,1],[1,5]]` has 2 mod5 isotropic directions and nonzero epsilon. All three source-independent hostile controls are CI-green and no F5-isotropy theorem is extrapolated to singular reductions.
