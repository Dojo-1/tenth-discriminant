Continue Professor Tao's tenth-discriminant programme without conflating number fields, auxiliary Grams and Dirichlet/Hecke/Selberg zeta functions. Keep the actual original TenthDiscriminant integer source:
- D>0, odd inert prime p with -D nonsquare modulo p, source order Z[sqrt(-D)];

Phase386 proved on paper, and checked in exact finite code, that every normalized derivative F_(r,s),j(z)=partial_Z^j P_(r,s)(z,star(z))/p^k is integral and depends modulo p^m only on source z modulo p^(m+1), regardless of k. This is a special Frobenius-factor assertion, **not** generic integer-polynomial quotient continuity.

## New paper theorem: count every Smith layer once

Let n=R*S, let F be the n by 2J|Q| normalized integer evaluation matrix, and assume the original source Gram is nonsingular. For m>=1, set C_m(Q)=the number of *occupied* source coordinate classes (x,y) modulo p^(m+1). This is different from the number of histogram weights nonzero modulo p.

For each fixed j and coordinate channel (real/imaginary), the column of F modulo p^m is constant on each occupied class. Thus the image of F over the finite local ring Z/p^mZ is generated by at most

  r_m=2*J*C_m(Q)

columns (or all n if this is larger than n). Let a_1,...,a_n be the nonnegative p-adic Smith exponents of the full-row-rank F. Smith normal form over Z_p, reduced modulo p^m, identifies its image with a direct sum of ideals p^(a_i)(Z/p^mZ), omitting zero ideals. **The minimum number of module generators** is exactly the number of a_i < m. Hence

  #{i:a_i>=m} >= max(0,n-2*J*C_m(Q)).

The identity sum_i a_i = sum_(m>=1) #{i:a_i>=m} gives, for every fixed M,

  sum_i a_i >= sum_(m=1)^M max(0,n-2*J*C_m(Q)).

This is a cumulative bound from DISTINCT p-adic Smith filtration layers, not repeated credit for the same first-order radical.

The original trace Gram is G=U^-1 Delta H Delta U^-T with Delta_ii=p^k_i, H=F B F^T and det U=1. Every n by n minor of F is divisible by p^(sum_i a_i). The exact integer Cauchy-Binet expansion

  det(F B F^T) = sum_(I subset scalar columns, |I|=n) det(F_I)^2 prod_(j in I) B_jj

then yields **two** p-powers for each evaluation index factor, since all weights B_jj=2 or 2D are integers. Consequently, for every M,

  v_p(det G) >= 2*F(p)
             + 2*sum_(m=1)^M max(0,n-2*J*C_m(Q)).

Here F(p)=sum_i k_i is the ALREADY counted Frobenius exponent. The additional term is relative to F after that normalization; any older evaluation-index or primitive pairing estimate must be compared carefully to prevent historical double counting. If det G=0, its positive finite integer valuation is undefined; original interpolation supplies the needed nonsingularity premise at production.

### Important counting distinction (an explicit falsifier)

Phase386's mod-p **Gram** rank used 59 classes with histogram weight nonzero modulo 3. These 59 cannot replace the 81 **occupied** classes in the evaluation-MODULE bound: p repeated identical scalar columns can cancel in the Gram modulo p while still generating a nonzero evaluation column. A tiny exact counterworld uses F=[[1,1,1,0],[0,0,0,1]], whose Gram has diagonal (3,1). The first coordinate's Gram weight vanishes modulo 3, yet the evaluation image has full rank 2. The new theorem intentionally counts **occupied** classes.

## Independently reproduced finite controls, and a preserved failure

The standard-library occupied_depths.py uses exact y-slice integer-square-root counting; a distinct modular residue-enumeration oracle checks q<=3^7, and direct point enumeration checks three small ellipses. It passed locally.

The separate SymPy integer Smith-normal-form test smith_matched_controls.py uses a 5x10 evaluation matrix with exponents (0,0,2,2,2), tests every visible generator layer, and verifies unimodular row/frame and column-permutation invariance. **An initially expected equality was falsified**: the source-toy Gram has v_3(det)=13, whereas twice the evaluation-index sum is only 12. The correct theorem is a lower bound; an additional pairing-radical factor may survive. This failed-equality record is retained, not hidden.
