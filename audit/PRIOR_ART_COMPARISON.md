## Sources actually inspected

- **Peter Murphy:** `DrMurphyIsIn/tenth-discriminant@f0995bf604056a98f0af0d182ed152c6bd996419`. Directly inspected actual source files `formalization/CN1/Main.lean`, `formalization/CN1/ChowlaSelberg/SevenEighths.lean`, `formalization/CN1/Finite/SplitPrime.lean`, `determinant/formalization/ELEM/Main.lean`, `determinant/formalization/ELEM/Divisibility/Main.lean`, and `determinant/formalization/ELEM/Endpoint/Comparison.lean`. The first route's source explicitly states the analytic \(7/8\) dependency and \(d\le652\) conclusion. The ELEM source directly formalizes the elementary companion's route and classification theorem. Neither project was built or proof terms replayed in this audit.
- **twinheterodox:** `twinheterodox/tenth-discriminant@95e8fe68da05790b99d828b5b6aff3f6dc479aa2`. Directly inspected `companions/elementary/proof.tex` and `companions/elementary/verify_finite.py`, not just the README. The proof states \(q<32768\), develops the auxiliary inert-prime/Green determinant argument, and specifies the finite sieve. The script exhausts 4,095 candidates and states the survivors. The external computation was inspected but not run here.
- **Antoine Olivier:** no artifact was located. GitHub repository search for “Antoine Olivier Heegner Lean” returned no result; GitHub code search required sign-in, and API/search-engine access was unavailable or unauthenticated. This is an access/search limitation, not evidence that no such work exists.

The prior sources are sources for what those projects claim and implement, not proof that their mathematical results are correct. Exact chronology and attribution were not independently verified. Murphy's ELEM code materially changes the originality assessment: an elementary formalization of the twinheterodox Green route already exists at the inspected commit, and its statement is at least as general in its field parameter as the canonical chart statement here. The present work appears to replace the auxiliary-prime/rectangular-radius argument with a guarded all-small-prime bridge and ellipse/trace-Gram estimates, and it targets a much larger explicit bound. Those may be genuine technical contributions, but the reviewed evidence does not establish a new mathematical obstruction independent of the Green/inertness determinant method.
