# Prior art — read this first

**Our track GREEN-H1-E is an independent rediscovery, not a new result.**

On 20 Oct 2026, in the comments of Tao's challenge post, *twinheterodox* (Codex-assisted) posted:
- v3 (12:45): under h=1, a direct lattice count of split primes replaces the Siegel-zero input (with Banks' determinant): q < 10⁶.
- v4 (13:44): the same split-prime count combined with **Ben Green's derivative Gram determinant**, evaluation points in a
  rectangle adapted to the quadratic-integer lattice, sharper resultant criterion: **q < 4000** (10-page paper, exact checks, independent review).
- v5 (14:36): Mellin averaging + Euler-product upper bound retaining composite norms: **q < 2000**.

Our work (started 21 Oct, without having read those comments) reached the same core idea, with weaker threshold (1.5·10⁴).
Differences that may still be of value: norm-ellipse evaluation set (idea: J. Vilela) with measured Hadamard slack
(~6–10% vs ~18–20% for a square grid); a blind-then-audit adversarial review (review/) with all defects fixed in the open.

Neighbouring routes in the same thread: Ross (Banks + zero-forcing lemma, d < 10¹⁰); Larsson (|D| < 50 000, Banks + Lu–Zaman–Zhao);
QRH routes (d ≤ 653, incl. Tao); van Dijk / Pescador variants of Green's argument.
